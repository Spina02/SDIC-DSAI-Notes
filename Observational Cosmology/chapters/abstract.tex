\section*{Preface}

This course provides a comprehensive overview of observational cosmology, covering the following topics:

\begin{itemize}
    \item Introduction
    \item Observational Facilities
    \item Active Galactic Nuclei (AGN)
    \item Interstellar Medium (ISM)
    \item Galaxies
    \item Cosmic Microwave Background (CMB) - Reionization
    \item Intracluster Medium (ICM)
    \item Cosmological Probes
    \item Cosmological Inference
\end{itemize}
